anaconda使用

在命令行可以直接使用，前面会显示（base等），如果没有显示，就需要使用

conda init powshell

重新激活，否则切换环境后，powshell处不会更改

几个常用的指令

  • conda info 查看当前环境信息
  • conda info -e 查看所有环境信息
  • conda activate name 激活name环境
  • conda create -n xxx python=x.x 新建环境
  • conda remove -n xxx –all 移除环境

毕业设计环境搭建

服务端搭建

  1. 首先使用pycharm导入项目，根据书中所说进入”~\MusicRecSys\MusicRec\z-others\files“命令行输入pip install -r requirement.txt即可一键安装所需依赖版本
  2. pycharm使用的为github认证后的免费版，中途出现学校邮箱被ban，只需在github上删除对应邮箱即可
  3. 接下来处理数据库，首先安装MySQL，自定义安装，紧安装MySQL sever与MySQL Workbench，最后安装个Navicat for MySQL，直接将项目提供数据库导入，该软件使用为网络破解版
  4. 参照推荐系统开发实战——项目代码的运行教程_《推荐系统开发实战》代码-CSDN博客与书籍中提到的位置修改项目代码，将配置给为本地配置
  5. 项目目录下输入下面指令，启动服务端

    python manage.py runserver 127.0.0.1:8000

前端搭建

  1. 环境在vscode下，npm与node以前都装好了，直接下载依赖项，将项目 中涉及到的IP都改为本地环回地址127.0.0.1

  2. 项目目录下输入下面指令即可启动前端

    npm run dev
