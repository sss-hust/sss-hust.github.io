DCU练习1

DCU练习1

熟悉利用DCU进行并行计算，DCU下编程主要分为以下几步：

  • 在DCU上划分空间，将待处理数据集传送到DCU上（存在优化空间，当前了解的是简单复制）
  • 设置线程数与线程块数，编写核函数，这一步是最重要的，函数逻辑决定了运行效率
  • 将运行结果传送回主机，并保存

DCU练习2

进一步熟悉DCU编程，进行线程间的合作，学习规约算法

以对二维数组的每一行进行softmax处理展开实验，在CPU上串行实现、DCU上每一行一个线程、DCU上每一行多个线程。

  • CPU串行实现：每一行找到最大值，减去后求和取指数。
  • DCU每一行一个线程：设置线程块与行数相同，线程块内只有一个线程，其余过程与CPU串行实现一致。
  • DCU每一行多个线程：设置线程块与行数相同，线程块内多个线程，每一个线程负责部分数据，采用与希尔排序类似的思路，找出部分数据中的最大值。再利用规约找整个数据中的最大值，即将整个数据集划分一半，前一半和后一半比较，较大值放到前者，这样处理完前一半后，缩小范围，将前一半划分两份，递归处理，最后最大值保存在线程0。在规约的时候涉及到线程之间数据比较，因此需要线程间的数据共享，每个线程块创建一个共享空间，每个线程有单独的内存空间，同一线程块内线程可以相互访问。最后的求和也按照前述思路。

！实验截图2

编译器若不使用优化，则每一行一个线程代价比CPU中串行还要高，因为包括了传输数据等开销；开启O1优化CPU与DCU中运行速度大大提速，O2对于单线程仍有大大提高，对于多线程则基本无变化。

DCU中的共享内存速度比用hipmalloc分配的全局内存更加快，同时生命周期也不一样。

Anaconda

anaconda使用

在命令行可以直接使用，前面会显示（base等），如果没有显示，就需要使用

conda init powshell

重新激活，否则切换环境后，powshell处不会更改

几个常用的指令

  • conda info 查看当前环境信息
  • conda info -e 查看所有环境信息
  • conda activate name 激活name环境
  • conda create -n xxx python=x.x 新建环境
  • conda remove -n xxx –all 移除环境

毕设0

毕业设计环境搭建

服务端搭建

  1. 首先使用pycharm导入项目，根据书中所说进入”~\MusicRecSys\MusicRec\z-others\files“命令行输入pip install -r requirement.txt即可一键安装所需依赖版本
  2. pycharm使用的为github认证后的免费版，中途出现学校邮箱被ban，只需在github上删除对应邮箱即可
  3. 接下来处理数据库，首先安装MySQL，自定义安装，紧安装MySQL sever与MySQL Workbench，最后安装个Navicat for MySQL，直接将项目提供数据库导入，该软件使用为网络破解版
  4. 参照推荐系统开发实战——项目代码的运行教程_《推荐系统开发实战》代码-CSDN博客与书籍中提到的位置修改项目代码，将配置给为本地配置
  5. 项目目录下输入下面指令，启动服务端

    python manage.py runserver 127.0.0.1:8000

前端搭建

  1. 环境在vscode下，npm与node以前都装好了，直接下载依赖项，将项目 中涉及到的IP都改为本地环回地址127.0.0.1

  2. 项目目录下输入下面指令即可启动前端

    npm run dev
