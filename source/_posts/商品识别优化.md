## 初步优化

首先进行文本预处理和分词逻辑，文本预处理将标签、符号等删去，得到由空格隔开的字符串，line 8即为实现函数，但对于非英文效果不是很好。后面的是分词器，利用jieba分词后，再利用词性筛选我们想要的，这里基本都保留了，除了一些停用词，同样，这里也存在对多语言的不适应，jieba是专门为中文文本设计的分词器，对于英文或者其它语言，将会拆分成最小单位，即依靠空格隔开，和理想效果不一样。

```python
# 文本预处理函数
def advanced_text_clean_product(text):
    """商品识别的文本预处理"""
    if pd.isna(text):
        return ""
    text = str(text)
    text = text.replace('&', '和').replace('vs', '对比').replace('VS', '对比')
    text = re.sub(r'[^\w\s-]', ' ', text)
    text = re.sub(r'\s+', ' ', text).strip()
    return text

def enhanced_product_tokenizer(text):
    """增强的产品分词器"""
    if not text:
        return []
    words = pseg.cut(text)
    tokens = []
    for word, flag in words:
        if len(word) > 1 and flag in ['n', 'nr', 'ns', 'nt', 'nz', 'eng', 'nx', 'nrt']:
            tokens.append(word)
        elif len(word) == 1 and word.isalnum():
            tokens.append(word)
    if len(tokens) < 2:
        tokens = [w for w in jieba.lcut(text) if len(w) > 1]
    return tokens

def enhanced_comment_tokenizer(text):
    """增强的评论分词器（保留名词和动词）"""
    if not text:
        return []
  
    words = pseg.cut(text)
    tokens = []
  
    # 保留的词性列表：名词 + 动词 + 英文动词
    valid_pos = {
        # 名词
        'n', 'nr', 'ns', 'nt', 'nz',
        # 动词
        'v', 'vd', 'vg',
        # 英文动词/名词
        'eng'
    }
  
    for word, flag in words:
        # 保留名词、动词、英文词
        if flag in valid_pos:
            tokens.append(word)
  
    # 如果结果太少，尝试全模式切分
    if len(tokens) < 2:
        tokens = [w for w in jieba.lcut(text) if len(w) > 1]
  
    return tokens
print("文本预处理函数定义完成")
```

根据试验，训练集加上评论数据后效果很差，因此数据准备方面，我选择的是训练集不额外加上评论数据，预测集额外加上评论数据（都是分词后的数据）。

这里先介绍TF-IDF，定义介绍如下，总的来说就是把当前句子中出现多并且总文本中出现少的单词权重加大。在代码中工作原理为利用训练集简历词汇表，对每个文本都计算值，这样，一行就是一个文本，一列就是一个词，构建出矩阵，完成向量化，接着把这个矩阵喂给分类器（LinearSVC），让它将特征与输出对应，就可以愉快的开始预测喽。

虽然处处感觉不靠谱，但是最终结果97分，即85个中有两个没有预测出来。我觉得是训练集里面（视频数据）基本都会出现商品单词，这样就可以拿大部分的分数，接下来无法直接看出来的，模型似乎会更加倾向于翻译（translator），又因为翻译占比更高，所以得分也不差。

> **TF-IDF (Term Frequency-Inverse Document Frequency)** 是一种统计方法，用于评估一个词对一个文档或语料库中的某份文档的重要性。它由两部分组成：
>
> * **TF (Term Frequency)**：词频，即某个词在文档中出现的次数除以文档总词数。
> * $$
>   TF(t)=\frac{该词在文档中的出现次数}{文档中的总词数}
>   $$
> * **IDF (Inverse Document Frequency)**：逆文档频率，衡量一个词的普遍重要性。如果一个词在很多文档中都出现，则其 IDF 值较低；反之，如果只在少数文档中出现，则其 IDF 值较高。
>   $$
>   IDF(t)=\log{\frac{总文档数}{包含该词的文档数+1}}
>   $$
>
> 最终的 TF-IDF 值是这两个值的乘积：
>
> $$
> TF-IDF(t,d)=TF(t,d)×IDF(t)
> $$

## 下一步优化

文本清洗应该没有什么好优化的，分词器可以考虑使用斯坦福的Stanza，适用于多语言。同时考虑从评论里提取需要的信息，即特征工程。最后预测算法也可以修改修改，TF-IDF只考虑词频统计，没有办法理解上下文，不过对于二分类问题应该问题不大。

本来想着分词优化优化，但转念一想，我直接把评论里面的目标词筛选出来不就好了，这样构建向量时，我们想要的词语占比将大大提高，同时因为逆词频取了对数，变化没那么快，所以效果应该不错。

让AI把常见语言全部列出来，然后使用正则表达去匹配，一旦找到就加入，同时选择去重，以防出现次数过多，带来反效果。

```python
def clean_text(text):
    if pd.isna(text):
        return ""
    text = str(text)
    # 替换特殊符号为统一空格
    text = re.sub(r'[^\w\s\-]', ' ', text)
    # 合并多个空格
    text = re.sub(r'\s+', ' ', text).strip()
    return text.lower()  # 统一小写便于匹配

def extract_keywords(text, keywords):
    if not text:
        return ""
  
    matched = []
    text_lower = text.lower()
  
    for kw in keywords:
        if kw.lower() in text_lower:
            matched.append(kw)
  
    return ",".join(list(set(matched)))  # 返回逗号分隔的字符串

# 清洗评论文本

# 提取关键词（返回列表）
comments_data['keywords_extracted'] = comments_data['cleaned_comment'].apply(
    lambda x: extract_keywords(x, keywords)
)

# 将每条评论提取出的关键词合并成一个列表
def merge_keywords(group):
    all_keywords = []
    for keywords_list in group:
        if keywords_list:
            all_keywords.extend(keywords_list.split(","))
    unique_keywords = list(set(all_keywords))
    return ",".join(unique_keywords) if unique_keywords else ""
```
