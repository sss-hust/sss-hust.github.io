接入新服务器第一件事，将ssh公钥放入.ssh中

```
mkdir -p ~/.ssh
chmod 700 ~/.ssh
echo "公钥" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

```

接着将export HF_ENDPOINT=https://hf-mirror.com写入.bashrc，以便后续下载模型数据等。

然后是将Anaconda安装上（之前有教程）

安装hugging-cli（access token每次都需要新建，没保存）

```
pip install -U huggingface_hub
hf auth login

```

如果服务器没有梯子，可以使用本地代理，只需要在ssh文件末尾加如下：

```
# 7897为本地代理端口
RemoteForward 1080 127.0.0.1:7897
# 远程服务器.bashrc中加
export ALL_PROXY=socks5://127.0.0.1:1080
# 如果远程没有pysocket，就要先安装，或者走http/https
```
