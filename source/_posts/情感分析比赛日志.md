最开始是通过datawhale了解到这个比赛，环境使用的是魔搭提供的免费GPU环境。在完成初期阶段后，平台驱动突然出问题了，显卡无法识别，只能用CPU跑，直接卡崩溃了。只能用另外的环境——阿里云给的免费额度。

但是又出现了github没法拉取得问题，想着用gitee转发下，结果lfs需要充钱才能用（太坑了），自己下载到本地又发现lfs控制得文件都是指针，无奈只能clone仓库了，这才把代码迁移过来。

迁移过来，又遇到了依赖地狱，没有办法跑起来，只能新建虚拟环境，使用以下命令安装Anaconda（参考[Python 在Ubuntu（或Linux）上通过命令行安装Anaconda|极客教程](https://geek-docs.com/python/python-ask-answer/625_python_install_anaconda_on_ubuntu_or_linux_via_command_line.html)）

```
# 获取安装包
wget https://repo.anaconda.com/archive/Anaconda3-2025.06-1-Linux-x86_64.sh
# 运行安装脚本
bash Anaconda3-2025.06-1-Linux-x86_64.sh
# 一路回车、yes即可安装成功
# 在.bashrc中添加环境依赖
# 添加Anaconda到系统环境变量
export PATH="/root/anaconda3/bin:$PATH"
source ~/.bashrc

```

安装完后，发现ipynb没有办法切换内核，于是继续寻找教程（参考[【最全指南】如何在 Jupyter Notebook 中切换/使用 conda 虚拟环境？\_多个conda环境 notebook用的哪个-CSDN博客](https://blog.csdn.net/u014264373/article/details/119390267)s）

```
conda activate my-conda-env    # this is the environment for your project and code
conda install ipykernel
conda deactivate

conda activate base      # could be also some other environment
conda install nb_conda_kernels
jupyter notebook

# 上述方法不行时，采用单独命令
python -m ipykernel install --user --name=your_env_name --display-name "Python (your_env_name)"
```

操作完毕后，即可切换啦，但是在命令行下载新的依赖后，似乎没法自动导入，需要重启内核，ipynb才可以识别到
