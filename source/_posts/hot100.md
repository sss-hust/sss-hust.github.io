## 160.相交链表

如果机器能像人一样能一眼看出来就好，理所应当想到遍历，利用哈希将指针变成数，统计其出现得次数。

根据数据的范围，会有原地hash操作，即全都取负数，~~面试官听了后让我直接回家~~

当然最优雅的做法还是双指针，两个相交列表最后部分肯定是相同的，不同的只有前面的部分，如果让两个指针走的路一样那就必然会相交，因此a指针走完去走b链，b同样，最后都会走那么长，或者都达到末尾。

这里要注意，把pa指向b，也算走一步，所以和向前走一步是二选一关系。

```c
struct ListNode *getIntersectionNode(struct ListNode *headA, struct ListNode *headB) {
    if(!headA || !headB) return NULL;
    struct ListNode *pa,*pb;
    pa = headA;pb = headB;
    while(pa != pb ){
        if(pa) pa = pa->next;
        else pa = headB;
        if(pb) pb = pb->next;
        else pb = headA;
    }
    if(pa) return pa;
    return NULL;
}
```

## 236.二叉树最近公共祖先

```c
bool find(int a, struct TreeNode *p){
    if(!p) return 0;
    if(p->val == a) return 1;
    if(find(a,p->left) || find(a,p->right)) return 1;
    return 0;
}
struct TreeNode* lowestCommonAncestor(struct TreeNode* root, struct TreeNode* p, struct TreeNode* q) {
    if(find(p->val,root->left) && find(q->val,root->left)) return lowestCommonAncestor(root->left,p,q);
    else if(find(p->val,root->right) && find(q->val,root->right)) return lowestCommonAncestor(root->right,p,q);
    else return root;
}
```

简单粗暴的递归，采用的是中序遍历，同时返回的信息较少，只能一次次遍历

这是一个非常好的问题！从直观的暴力解法（）进化到优雅的递归解法（），其实只需要跨越**三个思维台阶**。

一旦你掌握了这个思维路径，以后遇到很多树的题目（比如二叉树直径、最大路径和）都能迎刃而解。

### 台阶一：察觉“重复劳动” (The Redundancy)

首先，审视你的原代码。

* **你的逻辑**：“对于当前节点 `root`，我先派侦察兵（`find` 函数）去左边看看有没有 p，再派侦察兵去右边看看有没有 q……确任有了，我再自己走下去。”
* **痛点**：`find` 遍历了一遍子树，`lowestCommonAncestor` 又遍历了一遍同样的子树。节点被反复访问。

**思维转换：**

> 既然 `lowestCommonAncestor` 本身就要往下递归，我能不能**在递归回来的路上**直接带回信息，而不是出发前先去查询？

这叫从 **“先判断再遍历（Top-down）”** 转向 **“先遍历再汇报（Bottom-up / 后序遍历）”**。

### 台阶二：合并“返回值” (Information Merge)

这是最关键的一步技巧。

* **你的 `find` 函数**：返回 `bool`（在不在）。
* **你的主函数**：返回 `TreeNode*`（是哪个节点）。

为了把两个函数合并成一个，我们需要设计一种**包含更多信息量**的返回值。我们可以约定 `lowestCommonAncestor` 的返回值含义发生微小的变化：

* **原含义**：返回最近公共祖先。
* **扩充后的含义**：在子树里找 p 和 q。
* 如果**都没找到**，返回 `NULL`（相当于 `find` 返回 false）。
* 如果**找到了其中一个**（比如 p），返回那个节点 `p`（相当于 `find` 返回 true，且顺便带回了节点位置）。
* 如果**找到了最近公共祖先**，返回那个祖先节点。

**思维转换：**

> 不要只返回“是/否”，而是直接返回“找到的那个东西”。这样 `NULL` 代表没找到，`非空` 代表找到了。

### 台阶三：模拟“汇报机制” (The Bubble Up)

现在我们假设自己是树中间的一个节点 `root`，我们派出左右两个递归去搜寻。根据它们**回传**的结果，我们来做决策。

这时候，你的脑海里应该有这样一个**决策表**：

| 左边回传 (`left`)       | 右边回传 (`right`)      | **当前节点 (`root`) 的推断**                             | **决策 (return)**             |
| ------------------------- | ------------------------- | ---------------------------------------------------------------- | ----------------------------------- |
| **有东西** (比如 p) | **有东西** (比如 q) | 哇！p 在我不远处左边，q 在我不远处右边。**那我就是交点！** | 返回 `root` (我就是答案)          |
| **有东西**          | `NULL`                  | 左边找到了 p (或 p和q的祖先)，右边啥也没有。                     | 说明答案在左边，把 `left` 往上交  |
| `NULL`                  | **有东西**          | 左边啥也没有，右边找到了 q (或 p和q的祖先)。                     | 说明答案在右边，把 `right` 往上交 |
| `NULL`                  | `NULL`                  | 下面全是空的，没戏。                                             | 返回 `NULL`                       |

**这就是代码里那几行 `if` 的由来：**

```c
// 对应决策表第一行：两边都有，我就是LCA
if (left && right) return root; 
// 对应决策表第二、三行：哪边有就传哪边
return left ? left : right;

### 总结：如何培养这种直觉？

下次做树的题目时，试着按这个模版思考：

1. **遍历顺序**：与其“在当前节点做完所有判断再下去”（前序），不如“先一股脑冲到叶子节点，**在回溯的过程中**解决问题”（后序）。
2. **信息传递**：子树给父节点汇报什么信息最有用？（是仅仅汇报“有/无”，还是汇报“最大深度”、“最大路径和”或者“找到的节点指针”？）

**练习题推荐：**
为了巩固这种“自底向上汇报”的思维，你可以试试 **“二叉树的直径 (Diameter of Binary Tree)”** 或者 **“二叉树中的最大路径和 (Binary Tree Maximum Path Sum)”**。它们都需要子树向父节点汇报一个值，父节点再根据左右子树的值计算结果。
```

## 234.回文列表

一看，我们是怎么判断是否是回文列表呢？同时从左从右去对照就可以，那么我们首先要将后半部分翻转，所以分成两个函数——找中间点和翻转，其中找中间点偶数部分返回右边节点会更加方便判断。

```c
struct ListNode *overturn(struct ListNode *p){
    struct ListNode *pre,*next,*tmp;
    pre=NULL;tmp=p;
    while(tmp){
        next=tmp->next;
        tmp->next=pre;
        pre=tmp;
        tmp=next;
    }
    return pre;
}
struct ListNode *FindMiddle(struct ListNode *p){
    struct ListNode *slow,*fast;
    slow=p;fast=p;
    while(fast && fast->next){
        slow=slow->next;
        fast=fast->next->next;
    }
    return slow;
}
bool isPalindrome(struct ListNode* head) {
    struct ListNode *mid,*head2;
    mid=FindMiddle(head);
    head2=overturn(mid);
    while(head2){
        if(head->val != head2->val) return 0;
        head=head->next;head2=head2->next;
    }
    return 1;
}
```

## 739.每日温度

有点像雨滴问题，想到了用栈，但是写代码的时候磕磕碰碰！还得多练

```c
typedef struct node{
    int val;
    struct node *next;
}*node;
typedef struct tempe_list{
    node top;
}*tempe_list;
bool isempty(tempe_list s){
    return s->top == NULL;
}
void push(tempe_list s, int val) {
    node tmp=(node)malloc(sizeof(struct node));
    tmp->val=val;
    tmp->next=s->top;
    s->top=tmp;
}
int pop(tempe_list s){
    if(!s->top) return -1;
    node tmp=s->top;
    int val=tmp->val;
    s->top=s->top->next;
    free(tmp);
    return val;
}

int* dailyTemperatures(int* temperatures, int temperaturesSize, int* returnSize) {
    int *ReturnCount=(int *)malloc(sizeof(int)*temperaturesSize);
    *returnSize = temperaturesSize;
    tempe_list s=(tempe_list)malloc(sizeof(struct tempe_list));
    s->top=NULL;
    int tmp;
    for(int i=temperaturesSize-1;i>=0;i--){
        while(1){
            tmp = pop(s);
            if(tmp<0) {ReturnCount[i]=0;push(s,i);break;}
            if(temperatures[i]<temperatures[tmp]) {ReturnCount[i]=tmp-i;push(s,tmp);push(s,i);break;}
        }
    }
    return ReturnCount;
}
```

```c
struct TreeNode* invertTree(struct TreeNode* root) {

    if(!root->right && !root->left) return root;
```

## 221.最大正方形

一个正方形，一定要满足其左上方的点的右边以及下边和右下角都是1，以此就可以判断是否是正方形了，同时更大的正方形只需要遍历其右下角即可。实现起来发现有点问题，没有考虑到下方是否构成一个正方形，还是利用的信息少了，此时已经很接近动态规划的思想雏形了。

动态规划定义好dp[i][j]，其代表以位置i，j为右下角的正方形大小，据此推出

$$
dp_{i,j}=\begin{cases}0,&matrix_{i,j}=0\\\min(dp_{i-1,j-1},dp_{i-1,j},dp_{i,j-1})+1,&matrix_{i,j}=1\end{cases}
$$

小技巧，不想判断边界情况可以把dp矩阵第一行第一列左右各加新行新列。

```c
#define max(a,b) ((a) > (b) ? (a) : (b))
#define min(a,b,c) ((a) < (b) ? ((a) < (c) ? (a) : (c)) : ((b) < (c) ? (b) : (c)))
int maximalSquare(char** matrix, int matrixSize, int* matrixColSize) {
    int** dp = (int**)malloc((matrixSize + 1) * sizeof(int*));
    for (int i = 0; i <= matrixSize; i++) {
        dp[i] = (int*)malloc((*matrixColSize + 1) * sizeof(int));
        memset(dp[i], 0, (*matrixColSize + 1) * sizeof(int));
    }
    int i,j,max_size=0;
    for(i=0;i<matrixSize;i++){
        for(j=0;j<*matrixColSize;j++){
                if(matrix[i][j]=='0') dp[i+1][j+1]=0;
                else{
                    dp[i+1][j+1]=min(dp[i+1][j],dp[i][j+1],dp[i][j])+1;
                }
                max_size=max(max_size,dp[i+1][j+1]);
            }
        }
    for (int i = 0; i <= matrixSize; i++) {
        free(dp[i]);
    }
    free(dp);
    return max_size*max_size; 
    }
```

## 215.数组中的第K个最大元素

一开始想的是用单调栈，但是发现过去的元素还要使用，因此与栈相互违背，因为你每次插入都必须要把前面的取出来，取出来后再塞回去就比较复杂了，而使用大根堆就没有这个问题了，但手搓比较麻烦，还是使用快速排序吧！加上二分法的快排。当然这种情况最复杂的时候是$N^2$，但他好记忆啊！不改了。

```c
void swap(int *a,int *b){
    int tmp;
    tmp=*a;
    *a=*b;
    *b=tmp;
}
#include <time.h>

int quicksort(int left,int right,int *a){
    if(left>=right) return left;
    int i,j,index,pivot;
    index=left+rand()%(right-left+1);
    pivot=a[index];
    swap(&a[left],&a[index]);
    i=left;j=right;
    while(i<j){
        while(i<j && a[j]>=pivot) j--;
        while(i<j && a[i]<=pivot) i++;
        if(i<j) swap(&a[i],&a[j]);
    }
    swap(&a[left],&a[j]);
    // quicksort(left,j-1,a);
    // quicksort(j+1,right,a);
    return j;
}
int findKthLargest(int* nums, int numsSize, int k) {
    srand(time(NULL));
    int target=numsSize-k;
    int left,right;
    left=0;right=numsSize-1;
    while(1){
        int i=quicksort(left,right,nums);
        if(i == target) return nums[i];
        if(i>target) right=i-1;
        else left=i+1;
    }
}
```

## 207.课程表

一开始忘记图结构怎么组织的了，常用的两种——邻接矩阵与邻接表，矩阵是存储一个所有顶点构成的二维矩阵，表则是一个顶点数的一维数组，每一个都指向一个链表。

这题直接使用最慢的邻接矩阵就可以了，接下来就是判断是否有环了，第一时间想到的是挨个把边去掉就可以，即拓扑排序法，但是这样使用邻接矩阵会特别慢，因为不方便统计出入度，因此看题解，使用三色DFS法，对每一个未访问的节点（0），就设为正在访问中（1），如果在深度优先遍历的时候，发现遇到正在访问的点（即在访问栈中），说明有环，如果没环，结束后将当前节点设置为访问结束（2）.

```c
int **g,*color,num;
bool dfs(int index){
    color[index]=1;
    for(int i=0;i<num;i++){
        int tmp=g[index][i];
        if(tmp){
            if(color[i]==1) return 1;
            else if(color[i]==0 && dfs(i)) return 1;
  
        }
    }
    color[index]=2;
    return 0;
}
bool canFinish(int numCourses, int** prerequisites, int prerequisitesSize, int* prerequisitesColSize) {
    int a,b;
    color=(int *)calloc(numCourses,sizeof(int));
    g = (int **)malloc(numCourses * sizeof(int *));
    num=numCourses;
    for(int i=0;i<numCourses;i++)
        g[i]=(int *)calloc(numCourses,sizeof(int));
    for(int i=0;i<prerequisitesSize;i++){
        a=prerequisites[i][0];
        b=prerequisites[i][1];
        g[b][a]=1;
    }
    for(int i=0;i<numCourses;i++){
        if(!color[i] && dfs(i)) 
            return 0;
    }
    return 1;
}
```

## 200.岛屿数量

典型的dfs题，上色法解决，注意的是，当前解法还有可以优化的地方，不必要再新建一个数组，只要在原先的数组上将访问过的改成‘2’即可！

```c
int **g;
int a,b;
void dfs(int i,int j,char **c){
    if(i<0||i>=a||j<0||j>=b) return ;
    if(g[i][j]==1) return ;
    g[i][j]=1;
    if(c[i][j]=='0') return ;
    dfs(i-1,j,c);dfs(i+1,j,c);dfs(i,j-1,c);dfs(i,j+1,c);
}
int numIslands(char** grid, int gridSize, int* gridColSize) {
    g=(int **)malloc(sizeof(int *)*gridSize);
    a=gridSize;b=*gridColSize;
    int count=0;
    for(int i=0;i<gridSize;i++)
        g[i]=(int *)calloc(*gridColSize,sizeof(int));
    for(int i=0;i<gridSize;i++){
        for(int j=0;j<*gridColSize;j++){
            if(grid[i][j]=='0') g[i][j]=1;
            else if(g[i][j]==0){
                count++;
                dfs(i,j,grid);
            }
        }
    }
    return count;
}
```

## 198.打家劫舍

开始看题的时候以为是二维的，二维就有些复杂了，仔细一看只是一维，那就简单了，直接定义dp为从左到右偷到当前位置的最大收益，初始化两个值即可（记得判断是否有两个值！）

```c
#define MAX(a,b) (a)>(b)?(a):(b) 
int rob(int* nums, int numsSize) {
    int *dp=(int *)calloc(numsSize,sizeof(int));
    dp[0]=nums[0];
    if(numsSize==1) return dp[0];
    dp[1]=MAX(nums[0],nums[1]);
    for(int i=2;i<numsSize;i++){
        dp[i]=MAX(nums[i]+dp[i-2],dp[i-1]);
    }
    return dp[numsSize-1];
}
```

## 169.多数元素

## 238.除了自身以外数组的乘积

一开始肯定想的是暴力，遍历两遍就可以，但是这样会超时，因为时间复杂度为$n^2$了，所以得想办法优化，在逻辑上将数组变成一个矩阵，我们只需要对下三角和上三角分别乘就可以了，这样我们前面得遍历也好理解。

优化时，我们发现有很多我们其实是重复访问过得，因此可以用动态规划的思想，或者说递推，比如下三角，a[i]表示位置i左侧的乘积，那么a[i+1]=a[i]*nums[i]，这样我们就可以在O(n)复杂度下访问完下三角，同理，上三角也可以同样处理，从右下角往上递推！

```c
int* productExceptSelf(int* nums, int numsSize, int* returnSize) {
    int *a=(int *)calloc(numsSize,sizeof(int));
    for(int i=0;i<numsSize;i++) a[i]=1;
    *returnSize=numsSize;
    for(int i=1;i<numsSize;i++){
        a[i]=nums[i-1]*a[i-1];
    }
    int tmp=1;
    for(int i=numsSize-2;i>=0;i--){
        tmp=tmp*nums[i+1];
        a[i]*=tmp;
    }
    return a;
}
```

## [53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)

经典题目，具有多种解法，先说动态规划，我的理解是动态规划根本在于记忆，即通过之前的遍历，得到一些中间结果，而这个中间结果与我们关心的东西直接相关，并可以直接帮助后续问题，因此无需重复遍历已经遍历过的东西。因此状态转移方程就是在定义要记录什么信息。

本题扫描一遍后，就可以记录当前的最大数组和，如果前面的是负数，我加它变得比我自己更大了，那就保留它为最大的，否则从我开始当新的。

```c
#define MAX(a,b) (((a)>(b))?(a):(b))
#include <limits.h>
int maxSubArray(int* nums, int numsSize) {
    int dp[numsSize];
    dp[0]=nums[0];
    int max=dp[0];
    for(int i=1;i<numsSize;i++){
        dp[i]=MAX(dp[i-1]+nums[i],nums[i]);
        max=MAX(dp[i],max);
    }
    return max;
}
```

当然，评论区里看到有人用前缀和，也是和上面的思路有点相似，记录当前最大前缀，与最小前缀和，相减得到的就是当前最大子数组，记录并更新。

```c
#define max(a,b) a>b?a:b
#define min(a,b) a>b?b:a
int maxSubArray(int* nums, int numsSize) {
    int min1=0,max1=-99999,pre=0;
    for(int i=0;i<numsSize;i++){
        pre+=nums[i];
        max1=max(max1,pre-min1);
        min1=min(pre,min1);
    }
    return max1;
}
```

最后是分治法，还是将大问题化成小问题，二分区间，区间最大值由三部分决定——左到中间的最大和、包含中间的最大和、中间到右的最大和，这样就定义好子问题了，三个部分中，最难的是包含中间的值，它需要从中间不断向左右蔓延，去得到包含它的最大值，代码如下：

```c
#include <limits.h>  // 用于 INT_MIN（虽然这里没直接用，但好习惯）
#include <stdio.h>

// 辅助函数：计算跨越中点的最大子数组和
int maxCrossingSum(int* nums, int left, int mid, int right) {
    // 左半部分：从 mid-1 向左扩展，找最大和
    int left_sum_max = 0;
    int sum = 0;
    //关键，只需要记录最大值即可，所以不用管是哪些加起来最大
    for (int i = mid - 1; i >= left; i--) {
        sum += nums[i];
        if (sum > left_sum_max) {
            left_sum_max = sum;
        }
    }

    // 右半部分：从 mid+1 向右扩展，找最大和
    int right_sum_max = 0;
    sum = 0;
    for (int i = mid + 1; i <= right; i++) {
        sum += nums[i];
        if (sum > right_sum_max) {
            right_sum_max = sum;
        }
    }

    return left_sum_max + nums[mid] + right_sum_max;
}

// 分治主函数
int maxSubArrayHelper(int* nums, int left, int right) {
    if (left == right) {
        return nums[left];
    }

    int mid = (left + right) / 2;

    int left_max = maxSubArrayHelper(nums, left, mid);
    int right_max = maxSubArrayHelper(nums, mid + 1, right);
    int cross_max = maxCrossingSum(nums, left, mid, right);

    // 返回三者最大值
    int max_val = left_max;
    if (right_max > max_val) max_val = right_max;
    if (cross_max > max_val) max_val = cross_max;

    return max_val;
}

// 主接口函数
int maxSubArray(int* nums, int numsSize) {
    if (numsSize == 0) {
        return 0; // 或根据题意返回错误值，但 LeetCode 保证非空
    }
    return maxSubArrayHelper(nums, 0, numsSize - 1);
}
```

## [152. 乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)

这是上一题的升级版，因为变成负数后不一定没有翻盘的机会，就需要多记录些信息。本题题解最妙的是分类点，如果当前是负数，那一定是乘之前最小的可以得到当前最大的（除自己，后同）；如果是正数，就是与之前最大的相乘，可以得到阶段性最大，因此划分子问题。

```c
#define MAX(a, b) ((b) > (a) ? (b) : (a))
#define MIN(a, b) ((b) < (a) ? (b) : (a))
#include <limits.h>
int maxProduct(int* nums, int numsSize) {
    int dp_max[numsSize],dp_min[numsSize],max=nums[0];
    dp_max[0]=nums[0];dp_min[0]=nums[0];
    for(int i=1;i<numsSize;i++){
        dp_max[i]=MAX(dp_max[i-1]*nums[i],MAX(dp_min[i-1]*nums[i],nums[i]));
        dp_min[i]=MIN(dp_max[i-1]*nums[i],MIN(dp_min[i-1]*nums[i],nums[i]));
        max=MAX(max,MAX(dp_max[i],dp_min[i]));
    }
    return max;
}
```

```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };

struct ListNode* findMiddle(struct ListNode* head){
    //统一返回序列长度一半向上舍入。
    struct ListNode *slow,*fast;
    slow=head;fast=head;
    while(1){
        //循环先判断退出条件更优雅
        if(!(fast->next)) break;
        else if(!(fast->next->next)) break;
        slow=slow->next;
        fast=fast->next->next;
    }
    return slow;
}
struct ListNode* combine(struct ListNode* head1,struct ListNode* head2){
    //使用头结点，后续连接链表更加方便
    struct ListNode* head=calloc(1,sizeof(struct ListNode));
    struct ListNode* tmp=head;
    while(head1 && head2){
        if(head1->val <= head2->val){
            tmp->next=head1;
            head1=head1->next;
            tmp=tmp->next;
        }
        else{
            tmp->next=head2;
            head2=head2->next;
            tmp=tmp->next;
        }
    }
    if(!head1) tmp->next=head2;
    else tmp->next=head1;
    return head->next;
}
struct ListNode* sortList(struct ListNode* head) {
    //开始时先考虑特殊情况，即退出递归的条件，这里是由于找中点函数对于奇偶数列的处理，会有两种情况。
    if(!head) return head;
    if(!(head->next)) return head;
    //head1是中点断开后左侧链表，其它同理
    struct ListNode *head1,*head2,*middle;
    middle=findMiddle(head);
    head1=head;head2=middle->next;
    middle->next=NULL;
    //左右递归
    head1=sortList(head1);
    head2=sortList(head2);
    return combine(head1,head2);
}
```

```c
#include "uthash.h"
#include <stdlib.h>

// 1. 定义节点
typedef struct LRUnode {
    int val;
    int key;
    struct LRUnode* next;
    struct LRUnode* pre;
    UT_hash_handle hh; // 哈希句柄
} LRUnode; // 建议不要隐藏指针，这里去掉 *，显式使用 LRUnode*

// 2. 定义缓存对象
typedef struct {
    int capacity;       // 总容量
    int count;          // 当前数量
    LRUnode* hashHead;  // 【修正1】哈希表头指针放在结构体内，代替全局变量
    LRUnode* listHead;  // 双向链表的 Dummy Head
} LRUCache;

// 辅助函数：将节点插入到链表头部
void addToHead(LRUCache* obj, LRUnode* node) {
    node->next = obj->listHead->next;
    node->pre = obj->listHead;
    obj->listHead->next->pre = node;
    obj->listHead->next = node;
}

// 辅助函数：将节点从链表中摘除（但不释放内存）
void removeNode(LRUnode* node) {
    node->pre->next = node->next;
    node->next->pre = node->pre;
}

// 辅助函数：将节点移动到头部（复用上面两个函数）
void moveToHead(LRUCache* obj, LRUnode* node) {
    removeNode(node);
    addToHead(obj, node);
}

LRUCache* lRUCacheCreate(int capacity) {
    LRUCache* obj = calloc(1, sizeof(LRUCache));
    obj->capacity = capacity;
    obj->count = 0;
    obj->hashHead = NULL; // 初始化哈希表为空

    // 初始化 Dummy Head
    obj->listHead = calloc(1, sizeof(LRUnode));
    obj->listHead->next = obj->listHead;
    obj->listHead->pre = obj->listHead;

    return obj;
}

int lRUCacheGet(LRUCache* obj, int key) {
    LRUnode* result = NULL;
    // 【修正1】使用 obj->hashHead 而不是 global
    HASH_FIND_INT(obj->hashHead, &key, result);
  
    if (!result) {
        return -1;
    } else {
        moveToHead(obj, result); // 命中，移到头部
        return result->val;
    }
}

void lRUCachePut(LRUCache* obj, int key, int value) {
    LRUnode* result = NULL;
    HASH_FIND_INT(obj->hashHead, &key, result);

    if (result) {
        // 1. key 存在：更新值，移到头部
        result->val = value;
        moveToHead(obj, result);
    } else {
        // 2. key 不存在：需要新建
        LRUnode* newNode = calloc(1, sizeof(LRUnode));
        newNode->key = key;
        newNode->val = value;

        if (obj->count == obj->capacity) {
            // 容量已满：淘汰链表尾部（listHead->pre 就是尾部）
            LRUnode* tail = obj->listHead->pre;
  
            // 从哈希表中删除
            HASH_DEL(obj->hashHead, tail);
            // 从链表中移除
            removeNode(tail);
            // 释放内存
            free(tail);
            obj->count--;
        }

        // 插入新节点
        addToHead(obj, newNode);
        HASH_ADD_INT(obj->hashHead, key, newNode);
        obj->count++;
    }
}

void lRUCacheFree(LRUCache* obj) {
    // 【修正2】必须释放哈希表中的所有节点
    LRUnode *current, *tmp;
    HASH_ITER(hh, obj->hashHead, current, tmp) {
        HASH_DEL(obj->hashHead, current); // 从哈希表移除
        free(current); // 释放节点内存
    }
  
    // 释放 Dummy Head
    free(obj->listHead);
    // 释放 Cache 对象本身
    free(obj);
}
```

```c
struct ListNode *detectCycle(struct ListNode *head) {
    struct ListNode *slow=head,*fast=head;
    if(!head) return NULL;
    while(1){
        if(!(fast->next)) return NULL;
        if(!(fast->next->next)) return NULL;
        slow=slow->next;
        fast=fast->next->next;
        if(slow==fast) break;
    }
    fast=head;
    while(1){
        if(slow==fast) return slow;
        slow=slow->next;
        fast=fast->next;  
    }
 }
```

## [128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)

初看一点思路都没有，比较困惑在于这么大的数据范围，如何能有效得知其前面有多少个，也想过hash，但难点依然没解决，看了题解得知可以看前一个是否在，以此引发思路，遍历值域，查找每一个值其前一个是否在，如果在则长度加一，不在则当前长度置为一，大部分通过了，但是由于复杂度比较高，超时了。

```c

    int key;
    int count;
    UT_hash_handle hh;

    hash tmp;
    for(i=0;i<numsSize;i++){
        HASH_FIND_INT(head,&nums[i],tmp);
        if(!tmp) {
            tmp=calloc(1,sizeof(struct hash));
            tmp->key=nums[i];
            HASH_ADD_INT(head,key,tmp);
            min_=min(min_,nums[i]);
            max_=max(max_,nums[i]);
            continue;
        }
    }
    //接下来遍历hash表，从刚刚记录的最小值开始，如果其前一个值也在，就将当前值的count+前一个count
    i=min_;
    tmp=NULL;
    hash now;
    while(i>=min_ && i<=max_){
        int key = i - 1;
        HASH_FIND_INT(head, &i, now);
        if(now){
            HASH_FIND_INT(head, &key, tmp);
            if(tmp) now->count=tmp->count+1;
            else now->count++;
            max_count=max(max_count,now->count);

        i++;
    }
    return max_count;
}
```

```c
                val++;
```

## [124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)

路径就是边连起来的最长范围，可以这样考虑，当前节点最大值有三种情况，其本身值、本身值单加左右、本身值全加左右，当然，递归回去时，只能传前两个，因为本身加左右是没法作为路径继续传递下去的。

因此递归左右寻找即可，但这里有个问题，最长的未必在根节点出现，因此维护一个类全局（通过传地址实现）数值，其保存遍历过程中遇到的最大值。

树的困难题不难，只要无脑递归就行了，相比于数组的dp，这里的状态和子问题很容易定义，因此做下去非常简单。

```c
#define max(a,b) ((a)>(b)?(a):(b))
#define max3(a,b,c) (max(a,max(b,c)))
#define max4(a,b,c,d) (max(a,max3(b,c,d)))
int findmax(struct TreeNode* root,int* max_val){
    //退出递归条件为遇到空间点，返回0
    if(!root) return 0;
    int right=0,left=0;
    //依次递归左右节点，当前节点最大序列和来自于自身单加左右或者左右都加
    right=findmax(root->right,max_val);
    left=findmax(root->left,max_val);
    *max_val=max(*max_val,max4(root->val+right+left,root->val+right,root->val+left,root->val));
    return max3(root->val+right,root->val+left,root->val);
}
int maxPathSum(struct TreeNode* root) {
    int* a=calloc(1,sizeof(int));
    *a=INT_MIN;
    findmax(root,a);
    return *a;
}
```

### 记忆化搜索的“万能通用模板”

为了帮你建立框架，我总结了一个\*\*“记忆化搜索五步法”\*\*。以后遇到任何需要记忆化的递归（零钱兑换、爬楼梯、打家劫舍），直接套用这个结构：

#### 框架结构

1. **Base Case（递归出口）：** 越界了怎么办？到底了怎么办？
2. **Lookup（查表）：** 之前算过吗？算过直接返回。
3. **Init（初始化局部变量）：** 准备一个变量记录“当前这一层”的最优解（最大或最小）。
4. **Loop（遍历决策）：** 尝试每一个可能的选择（选硬币A、硬币B...），更新局部变量。
5. **Memoize & Return（记账并返回）：** 循环结束，把最终结果写入表，然后返回。

```c
#define min(a,b) ((a)>(b)?(b):(a))
#define max(a,b) ((a)>(b)?(a):(b))
int findanswer(int* coins, int coinsSize, int amount,int* dp){
    //退出条件，如果当前金额为0，只需要0个硬币就可以
    if(amount==0) return 0;
    if(amount<0) return -1;
    if(dp[amount]) return dp[amount];
    //记录全局最小硬币，index用来记录当前值是否可以被表示，如果可以就返回最小，否则就返回-1
    int min_count=INT_MAX,index=0;
    //遍历每一个子问题
    for(int i=0;i<coinsSize;i++){
        int tmp=findanswer(coins,coinsSize,amount-coins[i],dp); 
        if(tmp!=-1){
            index=1;
            min_count=min(min_count,tmp+1);
            dp[amount]=min_count;
        }
    }
    if(index) return min_count;
    dp[amount]=-1;
    return -1;
}
int coinChange(int* coins, int coinsSize, int amount) {
    int *dp=calloc(10001,sizeof(int));
    return findanswer(coins,coinsSize,amount,dp);
}
```

```c
int* findAnagrams(char* s, char* p, int* returnSize) {
    int a[26]={0},b[26]={0},len=strlen(p);
    for(int i=0;i<len;i++){
        b[p[i]-'a']+=1;
    }
    int left,right,*ans=calloc(strlen(s),sizeof(int)),index=0;
    for(right=0;right<strlen(s);right++){
        //进
        a[s[right]-'a']+=1;
        if(right+1<len) continue;
        //更新
        left=right-len+1;
        if(!memcmp(a,b,26*sizeof(int)))
            ans[index++]=left;
        //出
        a[s[left]-'a']-=1;
    }
    *returnSize=index;
    return ans;
}
```

```python
class Solution:
    def pathSum0(self, root, targetSum):
        if not root:
            return 0
        count = 1 if root.val == targetSum else 0
        count += self.pathSum0(root.left, targetSum - root.val)
        count += self.pathSum0(root.right, targetSum - root.val)

        return count
    def pathSum(self, root, targetSum):
        if not root:
            return 0
        ans = 0
        q = deque([root])
        while q:
            node = q.popleft()
            ans += self.pathSum0(node, targetSum)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        return ans
```

```python
        mp={0:1}
        ans=0

            if partsum-targetSum in mp :

            else :
                mp[partsum]=1

            mp[partsum]-=1
```

## [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

这题是上一题的简化版本，还是只会暴力做法，能够察觉到过往的信息没有办法使用上，也想过设计数组来存储信息，但是一是因为数太多，存储空间太大（为什么总是想不到用哈希表节省空间呢？数组本身就是一个hash表），二是往dp上面去想的，一直把问题分为当前值选与不选这样，没有察觉到其实是一个区间问题，可以使用前缀和。也不能这么说，一开始看到数组也想过用前缀和，但是依然要一次次遍历，O（n^2）的复杂度，想不到哪里还可以优化，于是就没有往这个思路去想了，但是看题解发现，首先把前缀和的式子变成s[i]=s[j]-k，这样我们就只要去找前缀和为s[i]的区间即可，找到了就说明存在一个区间，同时我们计算前缀和的时候可以把已经计算出来的值存到hash表中，key为值，value为出现次数。这样就可以在线性时间内找到想要的区间了。

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        fnums=[0] * (len(nums)+1)
        #初始化0为1，这样就包含了当前区间
        mp={0:1}
        ans=0
        for i,x in enumerate(nums):
            #更新前缀和数组
            fnums[i+1]=x+fnums[i]
            #更新子区间，判断之前的子区间是否出现想要的
            if fnums[i+1]-k in mp:
                ans+=mp[fnums[i+1]-k]  
            #更新hash表
            if fnums[i+1] in mp:
                mp[fnums[i+1]]+=1
            else :
                mp[fnums[i+1]]=1

        return ans
```

```python
class Solution:
```
